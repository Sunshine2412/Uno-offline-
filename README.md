# UNO Offline

Proyek Android native Kotlin untuk game kartu UNO offline.

## Fitur
- 1 pemain + 3 bot
- Tidak membutuhkan internet
- Kartu warna merah, kuning, hijau, biru
- Wild dan +4
- +2, Skip, Reverse
- Tombol UNO
- Mode portrait
- AI bot sederhana

## Cara membuka
1. Buka folder ini dengan Android Studio.
2. Tunggu Gradle Sync selesai.
3. Pilih `Build > Build APK(s)`.
4. APK debug biasanya berada di:
   `app/build/outputs/apk/debug/app-debug.apk`

Catatan:
Versi ini adalah fondasi playable. Aturan lanjutan seperti stacking +2/+4, challenge +4, animasi, suara, dan multiplayer lokal dapat ditambahkan kemudian.
